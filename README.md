# Koniki 🐴

Prosta gra karciana w przeglądarce: rozdaj karty z konikami, a potem odkrywaj je jedna po drugiej.

## Jak grać
1. Otwórz `index.html` w przeglądarce.
2. Naciśnij **Rozdaj** – karty zostaną potasowane i rozdane koszulką do góry.
3. Klikaj karty, żeby odkryć, który konik się pod nimi chowa. Ponowne kliknięcie zakrywa kartę.

## Ustawienia
Przycisk **⚙ Ustawienia** pozwala wpisać własne imiona koników (od 1 do 10). Imiona zapisują się w przeglądarce.

Domyślne koniki: Natalia, Aneta, Marianna, Adela, Laura, Nina.
